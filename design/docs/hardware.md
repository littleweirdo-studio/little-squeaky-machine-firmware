# Hardware

## Rear connectors and interfaces

On the rear of the machine you find different switches, mini-jacks and a USB connector.

```text
  ◉   ━= mini-jack (TRS) connector
 ╭─╮ 
 ╰┳╯  ━= switch
╭───╮ 
╰─┳─╯ ━= USB connector
```
